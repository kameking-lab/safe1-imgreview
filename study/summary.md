## 1. エグゼクティブ要点（1ページ）

### 1-1. 最多の事故の型 上位3（実数・xlsx）

**TGL（テールゲートリフター）n=1,878**

| 順位 | 事故の型 | 件数 | 構成比 |
|---:|---|---:|---:|
| 1 | はさまれ、巻き込まれ | 581 | 30.9% |
| 2 | 墜落、転落 | 457 | 24.3% |
| 3 | 激突され | 165 | 8.8% |

→ 上位3型で**全体の約64%**（1,203/1,878件）。

**高所作業車 n=1,149**

| 順位 | 事故の型 | 件数 | 構成比 |
|---:|---|---:|---:|
| 1 | 墜落、転落 | 392 | 34.1% |
| 2 | はさまれ、巻き込まれ | 281 | 24.5% |
| 3 | 転倒 | 84 | 7.3% |

→ 上位3型で**全体の約66%**（757/1,149件）。**感電30件**は高所作業車に特徴的（TGLには感電カテゴリ自体が出ない）。

> 走査規模：厚労省 死亡災害DB（1991–2018）＋死傷DB（2006–2017）の**約42万件**を走査し抽出。TGL内訳＝JNIOSH 1,386＋あんぜん 492、高所内訳＝JNIOSH 916＋あんぜん 233。

### 1-2. 特に死亡につながる型（**出典確認できず（要確認）**）

- 本データセットには**死亡/非死亡の区分列が無い**ため、「死亡につながりやすい型」の数値断定は**できない（要確認）**。
- 一般傾向として高所作業車は墜落・機体転倒（搭乗者の放出）が重篤化しやすい——とは現場知見として言えるが、本タスクの一次データからの**件数断定は避ける**。実死亡事例は `study/aerial.md`・`study/tgl.md`（検証URL付）を参照。

### 1-3. 現場で最初に言う危険ポイント3つ

**TGL**
1. **昇降板に乗って操作しない／可動部に手足を入れない**（はさまれ最多581件への直接対策）。
2. **全輪が板に載ってから昇降させる／倒れる荷役車（カゴ車・ロールボックス）は支えず退避**（墜落457・激突され165への対策）。
3. **2t以上のトラック荷台は昇降設備を使用し保護帽を着用**（2023/10/1〜対象拡大、安衛則第151条の67・第151条の74）。

**高所作業車**
1. **フルハーネスを作業床へ確実接続し、手すりを越えて乗り出さない**（墜落最多392件への対策、安衛則第194条の22）。
2. **頭上クリアランス（梁・トラス）を事前確認**（はさまれ281件への対策）。
3. **設置面の水平・支持力を確認しアウトリガーを全張り出し＋敷板／架空電線に近づけない**（転倒・感電への対策、第194条の11・基発759号）。

### 1-4. 法令の要点（一次資料で確認済の確定事項のみ）

- **TGL操作の特別教育＝令和6年（2024）2月1日〜義務**（安衛則第36条第5号の2／規程第7条の4）。**学科4時間＋実技2時間以上**。根拠＝基発0328第5号。
- **荷台の昇降設備・保護帽の対象拡大＝令和5年（2023）10月1日〜**（安衛則第151条の67・第151条の74）。
- **高所作業車の運転資格＝作業床高さ10mを境に二分**：10m以上＝技能講習（安衛令第20条第15号・就業制限）／10m未満（2m以上）＝特別教育（安衛則第36条第10号の5）。
- **作業計画→関係者周知→作業指揮者**（第194条の9・第194条の10）、**転倒防止＝アウトリガー・地盤・路肩**（第194条の11）、**作業床はフルハーネス義務**（第194条の22、垂直昇降式のみ例外）。
- **「安全帯→墜落制止用器具」改正＝平成31年（2019）2月1日施行**。実務目安**5m超はフルハーネス型**（理論上6.75m超は必須／ガイドライン基発0622第2号）。**旧規格「安全帯」は2022年（令和4）1月1日以降 販売・使用不可**。
- **離隔距離の目安＝特別高圧2m・高圧1.2m・低圧1m以上**（基発第759号。ただし**対象＝移動式クレーン等**で、高所作業車は機種差を明記のうえ実務目安として援用）。

## 2. 用語集（略語・専門用語の簡潔定義）

| 用語 | 定義 |
|---|---|
| **TGL（テールゲートリフター）** | 貨物自動車の後部に装備し、荷を昇降板（プラットフォーム）で地上⇔荷台間に積み卸す動力式荷役装置。本資料は**貨物自動車のTGLに限定**（塵芥車・トラッククレーン・フォークリフト等は含めない）。 |
| **昇降板（プラットフォーム）** | TGLで荷を載せて上下させる板。縁・段差からの墜落、板と荷台/地面の間のはさまれが典型危険。 |
| **カゴ車／ロールボックスパレット** | キャスター付きの箱型台車。TGL昇降板上での滑落・転倒が激突され/飛来落下の主因。 |
| **高所作業車** | 作業床（バスケット／搬器）を動力で上昇・移動させ人を高所へ運ぶ自走可能な機械。一次データ上の**起因物＝小分類コード146**。 |
| **ブーム式** | 屈伸・伸縮ブーム先端にバスケットを持つ形式。作業床がフルハーネス義務の対象。 |
| **垂直昇降式（シザース式）** | 作業床がほぼ真上に昇降する形式（はさみ式リフト等）。第194条の22のフルハーネス義務の**例外**。 |
| **トラック式／自走式** | 走行体の別。トラック架装で公道走行可＝トラック式、専用車台で構内移動＝自走式。 |
| **アウトリガー** | 機体を支え転倒を防ぐ張出脚。不同沈下防止のため敷板＋全張り出しが基本（第194条の11）。 |
| **作業床の高さ** | 作業床を最も高く上昇させた場合の床面の高さ（安衛令第10条第6号で定義）。規制対象は**2m以上**、資格区分の境界は**10m**。 |
| **就業制限業務** | 安衛法第61条に基づき有資格者でなければ就業できない業務。高所作業車は作業床10m以上が該当（技能講習修了が必要）。 |
| **特別教育** | 安衛法第59条第3項に基づく危険有害業務向けの教育。TGL操作（第36条第5号の2）／高所作業車10m未満（第36条第10号の5）等。 |
| **作業計画／作業指揮者** | 高所作業車使用前に策定・周知すべき作業方法を示した計画（第194条の9）と、それを指揮する選任者（第194条の10）。 |
| **墜落制止用器具** | 旧「安全帯」の改正後の呼称。高所では原則フルハーネス型（平成31年2月1日施行、旧安全帯は2022/1/1以降使用不可）。 |
| **フルハーネス型** | 肩・腿等で全身保持する墜落制止用器具。実務目安で5m超、理論上6.75m超で必須（基発0622第2号）。 |
| **離隔距離** | 充電部分と機体・ワイヤロープ等の間に確保すべき距離。基発759号の目安は特別高圧2m・高圧1.2m・低圧1m以上（移動式クレーン等向けを援用）。 |
| **JNIOSH（労働安全衛生総合研究所）** | 厚労省所管の研究機関。本資料の事故事例・整形CSVの主データ源の一つ。 |
| **あんぜん（職場のあんぜんサイト）** | 厚労省の災害事例・ヒヤリハットDB。本資料のもう一つのデータ源（anzeninfo.mhlw.go.jp）。 |
| **JAISH（安全衛生情報センター／中災防）** | 法令・通達本文を収録するサイト（jaish.gr.jp）。本資料の条文・通達の本文照合に使用。 |
| **基発（きはつ）** | 厚生労働省労働基準局長名で発出される通達。例：基発0328第5号（TGL等）、基発0622第2号（フルハーネス）、基発第759号（離隔距離）。 |
| **安衛法／安衛令／安衛則** | 労働安全衛生法／同施行令／労働安全衛生規則。 |
