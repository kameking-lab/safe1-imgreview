# D6 横断（TGL・高所作業車 共通の管理）＋イベント設営現場の留意

> 本章は TGL（テールゲートリフター）と高所作業車に**共通する安全管理**を整理し、さらに**イベント設営現場**（搬入出・パネル/什器・看板取付・天井/照明）特有の留意点をまとめる。
> 引用する法令・条文・施行日は、すでに **D3（study/tgl_law.md）／D5（study/aerial_law.md）で厚労省・通達本文を HTTP200＋本文一致確認済**のものを用い、本章末で主要URLを **2026-06-16 に再取得・再確認**したうえで再掲する。確認できない事項は「出典確認できず（要確認）」と明記し、断定しない。
> 危険ポイント・件数・実事故事例は D2（study/tgl.md）／D4（study/aerial.md）／stats（study/stats.md）の検証済み内容に依拠する。**TGL事例に塵芥車・クレーン・フォークリフト等を混ぜない／高所は起因物＝高所作業車のみ**の原則を本章でも維持する。

## 1. 両者に共通する管理サイクル（発注→搬入→作業→撤去）

TGL作業も高所作業車作業も、**「事前計画 → 有資格者の配置 → 関係者周知・指揮 → 作業前点検・KY → 作業中の立ち位置管理 → 異常時停止」**という同じ管理サイクルで事故の大半を防げる。両者の法令上の裏付けは下表のとおり（条文の詳細・施行日は D3/D5 で200確認済）。

| 管理要素 | TGL（貨物自動車荷役） | 高所作業車 | 共通の狙い |
|---|---|---|---|
| **有資格者の配置** | TGL操作の**特別教育**修了者（安衛則第36条第5号の2／**令和6年2月1日施行**。D3） | 作業床高さ**10m以上＝技能講習**／**10m未満＝特別教育**（安衛令第20条第15号・安衛則第36条第10号の5。D5） | 無資格者に操作させない。発注・搬入時に機体仕様と運転者資格を突合 |
| **作業計画／作業指揮者** | （TGL固有の作業計画条文は本タスク未確認＝要確認。実務上は荷役作業手順・役割分担を事前明確化） | **作業計画の策定（第194条の9）→関係労働者へ周知→作業指揮者の選任（第194条の10）**（D5） | 段取り・役割・合図を事前に決め、現場で逸脱させない |
| **作業開始前点検** | TGLは荷役装置として**作業開始前点検が必要（安衛則第151条の75第2号）**（D3。製造者の取扱説明書を参照） | **その日の作業開始前に制動・操作・作業装置を点検（第194条の27）**＋一年以内ごとの定期自主検査（第194条の23）（D5） | 始業前に可動部・制動・支持装置の異常を排除 |
| **転倒・逸走の防止** | 逸走防止措置（ブレーキ確実化等）＝安衛則第151条の11第3項（D3） | **アウトリガー張り出し・地盤の不同沈下防止・路肩崩壊防止（第194条の11）**＋逸走防止（D5） | 機械・荷役車・車両を「動かさない・倒さない」 |
| **墜落の防止** | 昇降設備の設置・保護帽（第151条の67・第151条の74／**令和5年10月1日施行**。荷台昇降は最大積載量2t以上で昇降設備使用が原則。D3） | 作業床上で**要求性能墜落制止用器具の使用義務（第194条の22。垂直昇降式は対象外）**。フルハーネスは**5m超目安／6.75m超は理論上必須**（D5） | 高さのある作業面からの墜落を物理的に止める |
| **リスクアセスメント／KY** | 作業前KY（昇降板の段差・端部・はさまれ範囲・荷役車の安定。D2） | 作業前KY（設置面・頭上クリアランス・架空電線・逸走・墜落制止用器具。D4） | 現場ごとの危険を作業前に洗い出し共有（根拠条文＝要確認。下記2参照） |

**横串の要点**：TGL=「最多はさまれ（581件）／墜落457件」、高所=「最多墜落（392件）／はさまれ281件」（実数＝stats.md）。**両者とも上位2型が「墜落」と「はさまれ」**であり、**①高さのある作業面からの墜落を止める（墜落制止用器具・昇降設備・端部管理）②可動部／挟まれ範囲の内側に身体を置かない**——この2点が共通の最重要対策になる。

## 2. リスクアセスメント／KY の位置づけ（管理手法として）

- **KY（危険予知）・作業前ミーティング**：その日の設置面・荷・頭上・周囲（電線/他作業）を全員で確認し、立ち位置と合図、異常時の停止手順を共有する。TGL・高所いずれも、実事故の多くが「**落下・転倒・逸走の"方向"に人が立っていた**」ことに起因する（D2/D4）。立ち位置の事前決めは最も費用対効果が高い。
- **リスクアセスメント（RA）**：作業の危険性・有害性を見積り、優先度をつけて対策する手法。**根拠条文（労働安全衛生法第28条の2＝努力義務と解される）の逐語200確認は本タスクでは未実施＝要確認**。本章では「RAは推奨される管理手法」として扱い、条番号の断定はしない。厚労省にRAの解説・教材を集めた portal がある（章末出典・HTTP200確認済）。
- 運用：RA/KYの結果は**作業計画（高所は第194条の9で法的に要求）**へ反映し、関係労働者へ周知（同条第3項）、作業指揮者（第194条の10）が現場で徹底する——という D5 で確認済の流れに乗せると、計画・周知・指揮・KYが一連で機能する。

## 3. イベント設営現場で特に留意すべき点

イベント設営は「**短工期・多能工・混在作業・仮設環境**」が常態で、TGL搬入と高所作業が同じ会場・同じ時間帯で並行しやすい。会場特性ごとの留意点を整理する（機序は D2/D4、法令は D3/D5 に準拠）。

### 3-1. 搬入出（TGL中心）
- **搬入口の段差・スロープ**：昇降板と地面・荷台の段差を解消してからカゴ車（ロールボックス）・台車を移す。**全輪が昇降板に確実に載ってから昇降**（後傾→荷滑落の防止。D2 事例3）。
- **時間に追われた近道行動**：搬入時刻に追われ、昇降設備を使わず段差をまたぐ／飛び降りる行動が誘発されやすい（D2）。**昇降板が荷台と同じ高さに上がり切ってから乗り移る**を徹底。
- **重い什器・パネルを満載した荷役車**：重心が高く、わずかな段差・接触で倒れる。**倒れてくる荷役車は支えず退避**、落下・転倒方向に身体を置かない（D2 事例1・2・4＝パイプ椅子台車はイベントに近い荷）。
- **混在動線**：来場前の搬入帯でも台車・フォーク等が交錯しやすい。動線・人/荷の交差点を事前に区分し、歯止め・輪止めで逸走を防ぐ。

### 3-2. パネル・什器・大型展示物の取扱い
- かさ高・重量物を人力＋TGLで扱うため、**荷の安定（重心・固定）と作業者の立ち位置**が要点。
- 立てた状態で運ぶ大型パネルは風（屋外）・接触で倒れやすい。**転倒方向に人を置かない／複数人で支点を決めて運ぶ**。

### 3-3. 看板・サイン取付（高所作業車中心）
- **身を乗り出す動作の多発**：看板・展示パネルへバスケットから手を伸ばす場面が多い。**手すりを越えて乗り出さず作業床を寄せ直す**、**フルハーネスを作業床へ確実接続**（D4 事例4＝乗り出しで約20m墜落）。
- **屋外・通り沿いの架空電線/引込線**：会場周辺の電線位置を事前確認。**接近のみでも放電（アーク）**するため、ブーム・作業床を近づけない。離隔距離の目安は**特別高圧2m・高圧1.2m・低圧1m 以上**（基発759号＝移動式クレーン等向け通達を機種差明記のうえ援用。D5）。電力会社連絡・防護管・監視人を基本とする（D4/D5）。

### 3-4. 天井トラス・照明の吊込み／配線（高所作業車中心）
- **頭上はさまれの最大リスク帯**：天井トラス・梁下・吊看板の直下での作業は、**作業床手すりと頭上構造物下面の間に頭部・頚部を挟圧**する型が多発（高所はさまれ281件。D4 事例2＝天井の梁で頚部挟圧）。
- 対策：**頭上クリアランスを先に確認**し、梁下では**上方を見ながら最小ストロークで微操作**、挟まれ範囲に頭部・上半身を置かない（D4）。

### 3-5. 仮設地盤・屋外会場（高所作業車の機体転倒）
- 屋外会場・搬入路・砂利/芝・仮設地盤など**整地されていない設置面**で作業床を上げる場面が多い（D4 事例1＝公園で機体転倒・2名放出）。
- 対策：設置前に**地盤の水平・支持力を確認**、**アウトリガーを規定どおり全張り出し＋敷板（敷鉄板）**、片効き・浮きがないか確認してから作業床を上げる（第194条の11。D5）。

### 3-6. 並行・混在作業と養生
- 設営は**他班の作業・通路・来場前動線**と混在しやすい。高所作業の**直下を立入禁止に区画**し、工具・部材の落下（飛来・落下）に備える。
- TGL搬入帯と高所作業帯が**時間的・空間的に重ならない**よう工程を組む。重なる場合は作業指揮者間で合図・区画を調整。

## 4. 横断チェックリスト（打合せで即言える共通要点）

**計画・体制（着手前）**
- [ ] 機体仕様（TGL搭載車／高所作業車の最大作業床高さ）と**運転者の資格**を突合（高所は10m以上=技能講習/未満=特別教育。TGLは特別教育。D3/D5）。
- [ ] 高所作業車は**作業計画を作成（第194条の9）→関係者へ周知→作業指揮者を選任（第194条の10）**。TGL荷役も手順・役割・合図を事前明確化。
- [ ] 搬入帯（TGL）と高所作業帯の**工程・区画を分離**。混在時は指揮者間で調整。

**作業前（始業時）**
- [ ] **作業開始前点検**：TGL＝荷役装置の点検（第151条の75第2号）／高所＝制動・操作・作業装置（第194条の27）。
- [ ] **KY**：落下・転倒・逸走・はさまれの「**方向**」を確認し、その方向に人を置かない立ち位置を全員で決める。
- [ ] 高所＝**設置面の水平・支持力／アウトリガー全張り出し・敷板／頭上クリアランス／架空電線**を確認（第194条の11）。

**作業中（共通の最重要2点）**
- [ ] **墜落を止める**：高所は**フルハーネスを作業床へ確実接続**（第194条の22。5m超目安・6.75m超必須）／TGLは段差をまたがず昇降設備使用・昇降板の開放端に背を向けない。
- [ ] **挟まれ範囲・落下方向の内側に身体を置かない**：TGL＝昇降板に乗って操作しない・可動部に手足を入れない／高所＝手すりと頭上構造物の間に頭部を置かない。
- [ ] **倒れてくる荷役車・機体は支えず退避**。重量物を人力で無理に止めない。

**撤去・終業**
- [ ] 逸走防止（輪止め・歯止め・ブレーキ確実化）。荷役車のストッパー。
- [ ] 異常を認めたら**直ちに停止・補修**（高所＝第194条の28）。
