# P-T5 写真生成メモ — TGL 降下中に足を地面との間にはさまれ（機序 I-T5 / 実事故 C-T5）

- **参照元絵**: `refs/I-T5_ref.gif`（厚労省 職場のあんぜんサイト ヒヤリ・ハット「はさまれ・巻き込まれ」の実在教材イラスト＝TGL昇降板が地面側へ傾き下降した際に作業者が足元（昇降板の縁と地面/床の境界）で下肢をはさまれる）。機種・PPEは I-T1 採用図（陸災防 TGL特別教育テキスト, `refs/I-T1_ref.jpg`）と力の向きの作画補助 z40（厚労省 高解像度図）を参照基準にTGL（テールゲートリフター付きキャブオーバー箱トラック・パワーゲート昇降板）に固定。
- **厳守要素**: 機械＝日本のキャブオーバー型TGL付き箱トラック（パワーゲート昇降板）／起因物＝**地面へ下降していく昇降板（昇降板の縁と地面/床の境界）**／接触点＝**作業者の足・足首が下降する昇降板の縁と地面の間ではさまれ（圧潰）**／力の向き＝昇降板が下方へ降り足を地面へ押し潰す。※「墜落」でも「荷の転倒」でもなく、足元の挟み込み点が危険源。
- **博展文脈調整**: 荷＝展示用資材（会場搬入の梱包箱／平板パネル／資材を積んだカゴ車）を背景に、会場搬入口（バックヤード荷捌き場、平コンクリート）。
- **生成方式**: `gen_v14_t5.mjs`（instagram-automation の Gemini ブラウザ方式流用、複製プロファイル geminiv14、Chrome killなし）。元絵を添付し「事故イラスト→写実写真」で再現。単一フレーム厳守（コラージュ/インセット/2コマ/線画化を強く禁止）、スパークル/ロゴ/可読文字/流血なしを指示。
