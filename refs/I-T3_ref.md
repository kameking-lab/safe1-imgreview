# I-T3 元絵 — TGL 後傾昇降板から荷(パネル)滑落で下敷き

- **採用ファイル**: `refs/I-T3_ref.png`（機序＝板状の荷の滑落→下敷き、の事故イラスト）
- **出所**: 労働新聞社「労働災害事例シート」イラスト（事例タイトル「金属の『はい』が崩れて下敷きになり死亡　作業主任者を選任していなかった」）
- **出所ページURL**: https://www.rodo.co.jp/accident/113575/
- **画像直URL**: https://www.rodo.co.jp/wp/wp-content/uploads/2021/09/24/ac0130301n-400x331.png
- **検索元**: Bing画像検索（別プロファイル anzen, Chrome killなし）クエリ「荷崩れ 板 滑落 下敷き 作業者 イラスト 労働災害 KYT」（refs/cand_T3b 収集）
- **3要素の確認**:
  - 機械/構造: 板状の荷を段積みした「はい」（背後にフォークリフト）。Phase3 では本機序を **TGL（テールゲートリフター）後傾昇降板** へ機種置換して再現する（下記「機種の基準」参照）。
  - 起因物: **平らな板状の荷（金属板＝パネル状）が滑落・崩落**して落下。I-T3 の「荷(パネル)」に直接対応。
  - 被災者: 作業者が落下した板の**下敷き**になる瞬間（衝撃線で明示）。
- **機序適合メモ**: I-T3 の機序は「後傾した昇降板の上の荷（パネル）が傾斜に沿って滑落し、昇降板の下／後方にいた作業者が下敷きになる」。本図は権威ある安全専門出版（労働新聞社）の実在災害事例イラストで、**板状の荷が滑り落ちて人が下敷きになる**力の向き・接触点・被災形態を最も明確に描く。これを機序（滑落→下敷き）の元絵とし、機種（TGL・後傾昇降板）は下記基準図で固定する。I-T2 と同方針（機序の瞬間を持つ図＋機種基準図の併用）。
- **機種の基準（Phase3 で厳守する TGL 形状・後傾幾何）**:
  - `refs/cand_T3/w34.jpeg`＝株式会社ジャパン・リリーフ コラム掲載の実車写真。**昇降板を地面まで後傾**させた日本仕様TGL（パワーゲート型）。後傾昇降板＝荷が滑落する傾斜面、という I-T3 の定義的危険幾何を明示。出所 https://www.japan-relief.jp/column/logistics/2369/
  - `refs/cand_T3/w42.png`＝「安全の王道」掲載のTGL型式図（アーム式/垂直式/後部格納式/床下格納式）。機種同定の補助。出所 https://anzen-oudou.com/?p=889
  - TGL機種の形状・作業者PPE（あごひもヘルメット/作業服/安全靴）の基準は I-T1 採用図（陸災防 TGL特別教育テキスト, `refs/I-T1_ref.jpg`）も参照。
- **博展文脈調整（Phase3 予定）**: TGL荷＝**展示用パネル**（会場搬入の平板）。後傾したTGL昇降板上で展示パネルが滑落し、昇降板下／後方の作業者が下敷きになる瞬間を、日本の現場・日本人・あごひもヘルメット/ハイビズ/安全靴・実在ロゴ無し・流血無しで描画する。

  - `refs/cand_T3/_candidates.json`（w01-w47）: w04=カゴ車転倒[I-T4寄り], w34=後傾TGL実車[機種基準に採用], w42=TGL型式図[補助に採用], w06/w13/w14=陸災防TGL教材表紙, w30=足はさまれ[I-T5寄り], 他はパワーゲート紹介写真/解説サムネで本機序の事故図でない。

- **不採用理由メモ**: ストック素材(pixta/ac-illust)は透かし入り・出所が安全機関でないため不可。TGL後傾昇降板から「パネルが滑落して人が下敷きになる瞬間」を一枚で描いた権威ある単独イラストは検索で確認できず、I-T1/I-T2 同様に「機序を持つ事故イラスト（x09）＋機種基準図（後傾TGL実車 w34・型式図 w42・陸災防教材）」の併用を採用。滑落→下敷きの瞬間と TGL機種の統合は Phase3 で描画する。
