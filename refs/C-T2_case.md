# C-T2 実事故照合 — TGL「昇降板と荷台の間に頭部はさまれ」(機序 I-T2)

- **機序ID**: I-T2 / C-T2（TGL 昇降板と荷台の間に頭部はさまれ）
- **一次データ**: 厚労省 死亡災害DB（JNIOSH整形CSV, ROUSAIDB）
  - 取得元ページ: https://www.jniosh.johas.go.jp/publication/houkoku/houkoku_2022_01.html
  - ローカル保存: `data/jniosh/SHIBO_2014.csv`〜`SHIBO_2018.csv`（死亡災害DB 5か年）

## 採用事例（primary）— 頭部はさまれが明示
- **引用元（ファイル名＋行番号）**: `data/jniosh/SHIBO_2018.csv` 139行目（ID=138）
- **発生年**: 2018年（平成30年）10月
- **事故の型**: はさまれ、巻き込まれ（コード7）
- **起因物**: 物上げ装置、運搬機械＞動力運搬機＞その他の動力運搬機（ゴミ収集車／コード229）
- **業種**: その他の事業＞派遣業
- **災害発生状況（抜粋）**:
  > ゴミ処理施設内のプラットホームで、一般家庭から収集した可燃ゴミの排出作業中、ゴミ収集車後部の扉(テールゲート)に頭部を挟まれたもの。
- **機序適合メモ**: 「後部のテールゲート（昇降式後部ゲート）に頭部を挟まれた」＝I-T2 元絵の「昇降板（テールゲート）と車体の間に頭部はさまれ」という接触点・はさまれ方向に直接合致。死亡災害DB内で“テールゲート＋頭部＋はさまれ型”を明示する唯一の死亡事例。

## 補強事例（alternate）— 「ゲートと荷台(車体後部)の間」の幾何が一致
- **引用元**: `data/jniosh/SHIBO_2014.csv` 815行目（ID=814）／2014年3月／事故の型=はさまれ、巻き込まれ（コード7）／起因物=トラック（221）／産業廃棄物処理業
- **抜粋**:
  > 古紙圧縮コンベヤー前にて、作業員が機械式ゴミ収集車を操作し、被災者とともに、回収した古紙の荷卸しと上昇させたテールゲート裏に挟まった段ボールの除去作業を終え、当該テールゲートを下降させたところ、被災者が当該テールゲートと当該収集車の後部に挟まれた。
- **メモ**: 「上昇させたテールゲートを下降させたところ、テールゲートと収集車後部の間に挟まれた」＝可動する後部ゲート（昇降板）と車体（荷台側）の間に身体がはさまれる、という I-T2 の力の向き・接触点（ゲート×車体）の幾何に一致。被災部位は頭部と明示されないため補強扱い。

## 不採用メモ
- `SHIBO_2018.csv` 850行目（ID=849, パワーゲート上で足を滑らせ塵芥車投入口へ落ち、回転盤に頭部を挟まれ）は、はさんだ相手が「塵芥車の回転盤」であり、「昇降板と荷台の間」ではないため不採用（起因物=トラック・型=はさまれだが接触点が異なる）。
- `SHIBO_2014.csv` 157行目（ID=156, パワーゲート昇降中に台車が荷台に引っかかり転倒、台車に下半身はさまれ頭部地面激突）は事故の型=転倒であり、はさまれ機序の主因が「台車」かつ頭部受傷は地面との衝突のため不採用。
- `SHIBO_2014.csv` 455行目（ID=454, パワーゲート上の被災者に後続車が追突）は交通事故（道路）型のため不採用。

## 留意（出典の正直な限界）
- 死亡災害DB 5か年には「運送用トラックのテールゲートリフター（TGL／パワーゲート）の作業床と荷台の間に“作業者の頭部”が挟まれた」純然たる事例は確認できなかった。
- 採用2件はいずれもゴミ収集車（塵芥車）の油圧式後部テールゲートだが、可動する後部ゲート板と車体（荷台側）との間に身体／頭部が挟まれるという機構・接触点・力の向きは I-T2 と同一であり、機序裏取りとして妥当と判断。創作・こじつけは行っていない。
